# 02 — UI/UX 및 디자인 구현 지침

## 1. 디자인 레퍼런스 해석
사용자가 첨부한 웰니스 브랜드 웹페이지를 시각적 기준으로 삼는다.
- 화면 상단에 작고 절제된 투명 네비게이션
- 화면을 넓게 사용하는 대형 인물 사진
- 따뜻한 브라운/베이지/오프화이트 색감
- 사진 위에 놓이는 큰 흰색 헤드라인
- 얇고 정돈된 타이포그래피와 충분한 여백
- 전체적으로 차분하고 프리미엄한 분위기

참고 이미지의 `Herb&Co` 브랜드명, 로고, 수상 배지, 상표 요소를 복제하지 않는다. 자체 브랜드 `MELLOW`를 사용한다.

## 2. 컬러 토큰
CSS 변수로 관리한다. 아래 값은 초기 기준이며 페이지 전체에서 일관되게 사용한다.
```css
:root {
  --color-ink: #2b211d;
  --color-brown: #5b4033;
  --color-brown-deep: #211915;
  --color-sand: #c7a98f;
  --color-cream: #f4eee7;
  --color-paper: #fbf9f6;
  --color-muted: #887a70;
  --color-line: #e4dbd2;
  --color-positive: #557b65;
  --color-negative: #a65c50;
  --color-neutral: #8b7968;
}
```

## 3. 타이포그래피
- 기본 폰트: 시스템 폰트 우선, 한국어 대체 폰트 포함
- 제목: 굵기는 500~600, 큰 크기, 줄 간격은 여유 있게
- 본문: 읽기 쉬운 14~16px
- 보조 설명: 대비가 충분한 muted 컬러
- 본문 전체를 대문자 스타일로 처리하지 않는다.

## 4. 화면 구성 및 배치
### A. Header
- 좌측: `MELLOW` 워드마크
- 우측: `ABOUT` 또는 `HOW IT WORKS` 같은 앵커 링크
- 배경: 히어로 위에서는 반투명 어두운 오버레이 또는 투명
- 모바일: 항목이 겹치지 않도록 간결하게 정리
- 실제 이동 기능이 없는 햄버거 버튼은 만들지 않는다.

### B. Hero
- 데스크톱에서 화면 상단의 핵심 영역으로 크게 구성
- 배경: 따뜻한 톤의 인물 클로즈업 또는 자연광 웰니스 사진
- 이미지 위에 어두운 그라데이션을 적용해 흰 글씨의 대비 확보
- 카피:
  - Eyebrow: `A MOMENT FOR YOURSELF`
  - Heading: `Pause. Feel.`
  - Heading second line: `Understand.`
  - Description: `당신의 문장에 담긴 감정의 결을 천천히 읽어드립니다.`
- 이미지 파일은 `assets/hero.jpg`를 기본 경로로 사용한다. 이미지가 없을 경우 단색 배경과 CSS 그라데이션으로 대체한다.
- 외부 이미지 URL을 임의로 핫링크하지 않는다. 이미지 라이선스를 확인한 파일만 사용한다.

### C. Analysis Section
- 히어로 아래에 크림/오프화이트 배경의 분석 영역 배치
- 섹션 제목: `오늘의 마음을 문장으로 남겨보세요`
- 설명: `짧은 문장부터 긴 생각까지, 최대 2,000자까지 분석할 수 있어요.`
- 넓은 textarea, 글자 수 표시, 분석 버튼 순서
- 저장 안내: `입력한 문장은 분석 결과와 함께 서비스 데이터베이스에 저장됩니다.`

### D. Result Section
- 분석 전에는 결과 영역을 숨기거나 안내 상태로 표시
- 분석 후 결과 카드 표시
- 감성 결과를 텍스트로 반드시 표시하고 색상만으로 구분하지 않는다.
- 결과 구성:
  1. `ANALYSIS RESULT` 라벨
  2. 긍정 / 부정 / 중립 결과
  3. `추정 신뢰도 87%` 형태의 점수
  4. 점수 막대(접근 가능한 텍스트 값 병행)
  5. `이렇게 판단했어요` 분석 이유
- 색상: 긍정은 차분한 그린, 부정은 muted terracotta, 중립은 taupe
- 애니메이션은 짧고 절제된 전환만 사용한다.

### E. Footer
- `AI 감성 분석은 참고용이며 전문적인 심리 진단이 아닙니다.`
- 입력 텍스트가 저장된다는 안내
- 저작권 표기는 임시 프로젝트명 기준

## 5. 반응형 기준
- 360px~767px: 모바일 1열, 헤더 간소화, 입력창과 버튼 전체 폭
- 768px~1023px: 태블릿, 콘텐츠 폭 제한
- 1024px 이상: 넓은 히어로와 중앙 정렬된 본문
- 본문 최대 폭은 약 900px, 텍스트 입력 영역은 충분한 높이를 제공
- 가로 스크롤이 생기지 않아야 한다.

## 6. 접근성 및 상태 디자인
- textarea에 연결된 label 제공
- 버튼은 키보드로 접근 가능하고 focus-visible 스타일 제공
- 결과 업데이트 영역은 `aria-live="polite"` 사용
- 로딩 중 버튼 비활성화 및 `분석 중...` 표시
- 오류는 색상뿐 아니라 텍스트와 아이콘/기호로 식별
- prefers-reduced-motion 설정을 존중
- 텍스트와 배경의 대비를 확인

## 7. 금지사항
- 참고 이미지의 브랜드 로고·문구·수상 배지를 복제하지 않는다.
- 결과를 색상만으로 표현하지 않는다.
- 화면에 실제 동작하지 않는 메뉴·버튼을 배치하지 않는다.
- 작은 화면에서 데스크톱 레이아웃을 축소만 하는 방식으로 처리하지 않는다.

## 8. 검증 및 완료 기준
- [ ] 첨부 레퍼런스와 같은 웜 브라운/베이지 무드
- [ ] 대형 히어로 이미지와 가독성 있는 오버레이
- [ ] 입력/버튼/결과 카드의 시각적 위계가 명확함
- [ ] 긍정·부정·중립을 색상과 텍스트로 함께 구분
- [ ] 360px, 768px, 1440px 화면에서 레이아웃 확인
- [ ] 키보드 포커스 및 오류·로딩 상태 확인
